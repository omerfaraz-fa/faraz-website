## Local Development

Clone the repository

```bash
git clone https://github.com/omerfaraz-fa/faraz-website.git
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## Deployment

Hosted on Vercel.

Every push to the main branch automatically deploys the latest version.
